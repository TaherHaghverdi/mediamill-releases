Media Mill 2.0

October 2026. Run any action without building a workflow, find items in a large Library, and the current macOS design.

New

  • Run one action on your items. Select items and choose Run… (⌘R). Workflows and single actions share one list, with search and your recent choices. An action's settings apply to that run only.
  • Run on items from an action's page. Every action page has Run on items….
  • Find the items you want, even in a large Library. Wherever you choose items, you can search titles, transcripts, and outputs, filter by tag, media, or status, sort, and select every item that can run in one click.
  • The current macOS design. On macOS 26 and later, the sidebar, toolbars, and controls use the current macOS look.
  • AI actions finish faster. On our test Mac, an AI action took less than half the time it took in 1.0.
  • Mac habits. Press Space for Quick Look, drag a link onto the Library to add it, and use ⌘S and ⌘R in the workflow editor. New workflow creates one right away, and workflows can be deleted. An item with no transcript has a one-click Transcribe.
  • Updates download on their own. From 2.0, new versions download in the background. When one is ready, select Relaunch to update. Required updates work the same way.
  • Downloads keep working when websites change. When you add a link, Media Mill updates its website support if it's out of date. If a download still fails in a way a newer version could fix, Media Mill updates and tries once more.

Changed

  • Make subtitled copy is gone. Choose Run… > Burn subtitles instead. To burn translated subtitles, set Language to the translation you want.
  • Burned subtitles are easier to read. They're larger and bolder, they fit vertical phone videos, Persian and Arabic read right to left, and Chinese, Japanese, and Korean characters display correctly.
  • Speech detection is more accurate. Short real speech and song lyrics now count as speech. Phrases a transcription engine invents over silence still don't. Some existing items may show a different status.
  • Live streams and upcoming premieres are declined, with a message that says why.
  • Media Mill ignores your own yt-dlp settings file. Downloads use Media Mill's settings only.

Fixed

  • YouTube downloads work again. In 1.0, many YouTube videos stopped partway through with an error.
  • Export with Replace never deletes a file before the new copy is saved.
  • Quitting during a run no longer restarts a run you stopped or repeats a finished step.
  • Library search shows every match. It used to stop at 25.
  • Assistants connected to Media Mill get accurate status for links they add, while the link's workflow is still running.
  • More than 100 other fixes from a full review of the app.

Updating

If you have Media Mill 1.0, it asks you to update before you continue. Follow the steps on the update page. Your Library, workflows, actions, and settings stay as they are.

Assistants connected to Media Mill keep working. If one reports a lost connection right after the update, try the request again.
