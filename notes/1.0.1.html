Media Mill 1.0.1

August 9, 2026. Fixes for three problems found right after 1.0.0.

Fixed

  • Media Mill no longer asks to access data from other apps when it starts. It was asking on every launch, and it waited for the answer before the window could open. Media Mill now declares the one shared folder it uses, so there is nothing to ask about.
  • The Safari extension works. The same problem stopped Media Mill from opening the connection Safari talks to, so Save to Media Mill could never reach the app.
  • Chrome-family browser setup is now something you turn on. Media Mill used to write its connector file into every Chromium browser on the Mac at startup, which is what most of those permission requests were for. It now leaves browsers alone until you ask for browser capture.

Also

The download is now a normal Mac disk image: open it and drag Media Mill to Applications.

Updating

Media Mill installs this the usual way, from the update card in Activity. Nothing in your Library changes.
