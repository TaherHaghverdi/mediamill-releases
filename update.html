Update Media Mill

Your copy of Media Mill needs the latest version to continue. Your Library, workflows, actions, and settings stay as they are.

The download should start on its own. If it doesn't, select Download Media Mill.

Download Media Mill

Install the latest version

  1. Quit Media Mill. On the update screen, select Quit Media Mill, or choose Media Mill > Quit Media Mill.
  2. Open the MediaMill.dmg you just downloaded. In the window that opens, drag Media Mill to the Applications folder.
  3. When your Mac asks, choose Replace.
  4. Open Media Mill from your Applications folder.

The update screen goes away when the new version opens.

If it doesn't work

  • Your Mac says Media Mill is in use. Media Mill is still open. Quit it, then drag it to Applications again.
  • The update screen comes back. An older copy opened. Open the copy in your Applications folder, and move any other copies of Media Mill to the Trash.
  • Something else. Contact Media Mill support.

Media Mill needs a Mac with Apple silicon and macOS 15 or later.
